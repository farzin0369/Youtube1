اتصال به مخزن GitHub

برای ارسال پیام و خواندن پاسخ اجرا، یک Fine-grained Personal Access Token محدود به مخزن Youtube1 بساز. توکن فقط تا پایان همین نشست مرورگر در sessionStorage می‌ماند و برای GitHub API ارسال می‌شود. این مخزن عمومی است؛ پیام‌ها و پاسخ‌ها را محرمانه فرض نکن و اطلاعات حساس نفرست.

  1. در ساخت توکن جدید، فقط مخزن Youtube1 را انتخاب کن.
  2. دسترسی Actions: Read and write و Checks: Read-only را فعال کن. Metadata به‌صورت خودکار خواندنی است.
  3. توکن را اینجا وارد و ذخیره کن. هر زمان خواستی با «پاک‌کردن توکن» آن را از این مرورگر حذف کن.
