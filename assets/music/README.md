# Background music

The pipeline does not redistribute downloaded songs. Its five built-in chord/texture presets synthesize a quiet, original ambient bed at render time and rotate by run ID, so no paid subscription or unverified audio asset is required. If you place `.wav` or `.mp3` files here, use only music you created or music whose license explicitly allows your intended YouTube use, and retain its license/credit details; the renderer selects one of your local files for that run.
