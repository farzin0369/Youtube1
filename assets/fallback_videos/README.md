# Local visual fallback

Place creator-owned, public-domain, or otherwise properly licensed `.mp4`, `.mov`, or `.m4v` clips here. If Pexels is unavailable, the renderer uses these clips in a loop and crops them to the vertical video format. Keep the source and license records with your own production records; do not add unlicensed downloads to the repository. If this folder contains no clips, the pipeline creates abstract animated backgrounds locally instead of pretending they are real footage.
