سلام! چطور کمک کنم؟

سؤال بپرس، ایده‌پردازی کن یا یکی از میانبرها را انتخاب کن.

برای پاسخ هوش مصنوعی، سرویس سازگار را در تنظیمات وصل کن. کلید API را در مخزن GitHub قرار نده.

تنظیمات هوش مصنوعی

اگر بک‌اند را راه‌اندازی کردی، این دو مقدار برای اتصال امن‌تر به آن است. رمز دسترسی فقط تا پایان نشست مرورگر نگهداری می‌شود.

چت فقط از مسیر بک‌اند امن و متصل به OpenClaw انجام می‌شود. کلید مدل را داخل مرورگر وارد نکن؛ توکن Gateway باید فقط در Secrets سرویس Cloudflare نگهداری شود.
