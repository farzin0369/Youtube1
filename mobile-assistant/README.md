# همراه هوشمند — دستیار موبایل فارسی

این پوشه یک وب‌اپلیکیشن پیش‌رونده (PWA) راست‌چین برای اندروید است. رابط چت، میانبرهای گوگل و GitHub، بررسی فهرست فایل‌ها، و اتصال اختیاری به بک‌اند محدودشده را دارد.

## وضعیت واقعی این نسخه

- رابط کاربری موبایل، فایل manifest و Service Worker در مخزن وجود دارند.
- بک‌اند برای ارسال پیام چت به **OpenClaw Gateway خود کاربر** تنظیم شده است؛ این مخزن خودش Gateway را میزبانی یا اجرا نمی‌کند.
- چت فقط از مسیر بک‌اند مستقرشده کار می‌کند؛ نشانی Worker و رمز دسترسی برنامه باید در تنظیمات ثبت شوند و Gateway باید از اینترنت به‌صورت امن قابل دسترسی باشد. اتصال مستقیم به API عمومی از رابط حذف شده است.
- دکمهٔ Google جست‌وجو را در مرورگر باز می‌کند؛ دکمهٔ GitHub مخزن را باز می‌کند.
- «پیشنهاد تغییر GitHub» پس از راه‌اندازی بک‌اند، فقط در مسیرهای مجاز branch و Draft PR ایجاد می‌کند؛ merge نمی‌کند. این قابلیت هنوز زنده مستقر یا آزمایش نشده است.
- هرگز توکن OpenClaw یا GitHub را در JavaScript، تنظیمات قابل انتشار، یا مخزن commit نکنید.

## نصب روی اندروید

این پوشه باید از HTTPS میزبانی شود (برای نمونه GitHub Pages). پس از فعال‌سازی Pages برای مسیر/شاخهٔ مناسب، در Chrome نشانی وب‌اپ را باز کنید و از منو گزینهٔ **Install app** یا **Add to Home screen** را انتخاب کنید. باز کردن فایل HTML به‌صورت محلی، نصب PWA را فعال نمی‌کند.

## اتصال OpenClaw

در تنظیمات اپ فقط نشانی Worker و رمز `APP_ACCESS_SECRET` را وارد کنید. در تنظیمات بک‌اند Cloudflare Worker، موارد زیر را تنظیم کنید:

- `OPENCLAW_CHAT_URL`: نشانی کامل HTTPS endpoint سازگار با chat-completions که Gateway شما ارائه می‌کند.
- `OPENCLAW_GATEWAY_TOKEN`: به‌عنوان Worker Secret؛ هرگز در اپ موبایل قرار نگیرد.
- `OPENCLAW_MODEL`: اختیاری؛ شناسهٔ مدل/عامل مورد قبول Gateway.
- `APP_ACCESS_SECRET`: رمز تصادفی برای احراز هویت برنامه.
- `GITHUB_TOKEN`: توکن محدود به همین مخزن با کمترین دسترسی لازم.

Gateway باید روی میزبان دائمی و از Worker قابل دسترسی باشد. آدرس localhost، شبکهٔ خصوصی یا Colab خاموش/موقت کار نمی‌کند. خود مخزن Gateway را نصب، میزبانی یا روشن نمی‌کند.

## گام‌های لازم پیش از استفاده

1. Worker را deploy کنید و secretها/variableها را فقط در Cloudflare تنظیم کنید.
2. مقدار `ALLOWED_ORIGIN` را دقیقاً برابر origin HTTPS وب‌اپ قرار دهید.
3. نشانی Worker و `APP_ACCESS_SECRET` را در تنظیمات اپ وارد کنید.
4. سلامت Worker و یک درخواست چت واقعی از طریق OpenClaw را آزمایش کنید.

**وضعیت فعلی:** استقرار و اتصال زنده هنوز تأیید نشده‌اند؛ وجود کد به‌تنهایی به معنی اجرای واقعی دستیار نیست. کلیدهای API مدل دیگر از داخل مرورگر پشتیبانی نمی‌شوند.
