# همراه هوشمند — دستیار موبایل فارسی

این پوشه یک وب‌اپلیکیشن پیش‌رونده (PWA) راست‌چین و قابل نصب روی اندروید است. رابط چت، تنظیمات ارائه‌دهندهٔ سازگار با OpenAI، نگهداری تاریخچهٔ کوتاه مکالمه در همان نشست، میانبر گوگل و پیوند مخزن GitHub را دارد.

## وضعیت واقعی این نسخه

- رابط کاربری موبایل، فایل manifest و Service Worker آماده شده‌اند.
- پاسخ هوش مصنوعی فقط پس از تنظیم URL، نام مدل و API key یک ارائه‌دهندهٔ سازگار کار می‌کند. این برنامه مدل ابری رایگان داخلی یا API key همراه خود ندارد.
- دکمهٔ Google جست‌وجو را در مرورگر باز می‌کند؛ دکمهٔ GitHub مخزن را باز می‌کند.
- این نسخه **هنوز عامل خودمختار برای ویرایش مخزن، کنترل همهٔ برنامه‌های گوشی یا اجرای دستورات اندروید نیست**. چنین قابلیت‌هایی به بک‌اند امن، احراز هویت GitHub با مجوز محدود، ابزارهای اجرایی محدودشده و تأیید کاربر برای اقدامات حساس نیاز دارد.
- کلید API در localStorage مرورگر نگهداری می‌شود؛ برای استفادهٔ حساس/تولیدی باید به بک‌اند امن با احراز هویت منتقل شود. کلید را در GitHub commit نکنید.
- API provider باید درخواست‌های مرورگر را از طریق CORS مجاز بداند.

## نصب روی اندروید

این پوشه باید از HTTPS میزبانی شود (برای نمونه GitHub Pages). پس از فعال‌سازی Pages برای مسیر/شاخهٔ مناسب، در Chrome نشانی وب‌اپ را باز کنید و از منو گزینهٔ **Install app** یا **Add to Home screen** را انتخاب کنید. باز کردن فایل HTML به‌صورت محلی، نصب PWA را فعال نمی‌کند.

## اتصال مدل

در تنظیمات برنامه:
1. Base URL سرویس سازگار با OpenAI را وارد کنید (مثلاً نشانی پایه‌ای که مسیر `/chat/completions` را پشتیبانی می‌کند).
2. نام دقیق مدل همان سرویس را وارد کنید.
3. کلید API را وارد کنید.

این رابط کلید را فقط روی همان مرورگر ذخیره می‌کند؛ این روش برای نسخهٔ نمایشی است، نه راهکار امنیتی نهایی.

## گام‌های لازم برای عامل واقعی GitHub

1. ورود OAuth/device flow با دسترسی محدود به مخزن منتخب.
2. بک‌اند با ذخیره‌سازی امن توکن، نه در JavaScript یا مخزن.
3. ابزارهای مجاز برای خواندن فایل‌ها، ساخت branch، اجرای تست و ساخت Pull Request.
4. محدودسازی عملیات مخرب و درخواست تأیید قبل از merge، انتشار یا دسترسی به secrets.
5. تست خودکار و استقرار HTTPS.
