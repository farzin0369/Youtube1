# کارخانهٔ فارسی بامو (HTML → ویدیو)

- `bank.py` اعتبارسنجی، تشخیص ایدهٔ تکراری، انتخاب بدون تکرار
- `seed_data.py` ۲۶ ایدهٔ دست‌نویس و بررسی‌شده (بذر بانک)
- `expand_bank.py` رشد بانک با مدل رایگان + راستی‌آزمایی مستقل (نیاز به OPENROUTER_API_KEY)
- `tts.py` صدای فارسی جمله‌به‌جمله (زمان‌بندی دقیق) + موسیقی زمینه
- `compose.py` ساخت HTML عمودی ۱۰۸۰×۱۹۲۰ با ۷ سبک تصویری رویه‌ای و زیرنویس کلمه‌به‌کلمه
- `run.py` ایده ← صدا ← رندر HyperFrames ← کنترل کیفیت ← آپلود اختیاری

اجرا: `python -m fa_factory.run --dry-run` ، `python -m fa_factory.run --publish --privacy private`
زمان‌بندی روزانه عمداً خاموش است تا یک نمونه را تأیید کنید.
