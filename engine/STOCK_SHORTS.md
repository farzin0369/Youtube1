# موتور جدید: شورت یوتیوب با فیلم واقعی (نه AI چهره)

## چرا موتور قبلی را کنار گذاشتیم؟
تصاویر SDXL/SVD روی کانال معنوی شبیه «محتوای جعلی ضعیف» دیده می‌شوند و ریسک رد شدن / بی‌اعتمادی مخاطب دارد.

## استاندارد واقعی کانال‌های Faceless یوتیوب
1. **فیلم استوک واقعی** (Pexels / Pixabay) — نه چهره AI
2. **صدای راوی** (Edge-TTS رایگان، فارسی)
3. **زیرنویس درشت و خوانا**
4. **موسیقی پس‌زمینه آرام** (اختیاری)
5. فرمت **۹:۱۶ / ۱۰۸۰p**

## موتور مرجع در گیت‌هاب
**MoneyPrinterTurbo** — `https://github.com/harry0703/MoneyPrinterTurbo`  
(~۱۳۰k⭐، MIT، موضوع → اسکریپت → استوک → صدا → زیرنویس → رندر)

پروژه‌های مشابه:
- ShortGPT
- purffle-shorts
- SuperShorts

## موتور سبک داخل این مخزن
`engine/stock_short.py` — نسخه سبک و مستقل:
- اسکریپت فارسی ثابت یا از JSON
- جستجوی Pexels (کلید رایگان)
- Edge-TTS فارسی
- مونتاژ FFmpeg عمودی + زیرنویس
- **بدون GPU**

## راه‌اندازی
1. کلید رایگان Pexels: https://www.pexels.com/api/
2. در GitHub Secrets: `PEXELS_API_KEY`
3. اجرای workflow: `stock_shorts.yml`
