# کنترل صحنه (به‌جای Clew)

**Clew / ClewCode** ابزار کدنویسی و پیگیری کار است، نه موتور ساخت انیمیشن رایگان.

برای هماهنگی متن–تصویر–صدا در این پروژه از **ایجنت‌های قاعده‌ای محلی** استفاده می‌شود:

1. **Orthography agent** — اعراب روی متن گفتار برای Edge-TTS Farid
2. **Scene-lock agent** — هر جمله فقط به کلیپ‌های Mixkit مرتبط وصل است (مثلاً بغل بره → فقط فیلم بره/گوسفند، نه دو پسر)
3. **Duration agent** — طول کلیپ = طول همان خط صدا

## چرا Mixkit؟
حرکت واقعی دوربین؛ قبلاً در همین پروژه جواب داده.

## CrewAI
فریمورک چندایجنتی اپن‌سورس است ولی معمولاً به API مدل زبانی نیاز دارد؛ برای خط تولید کاملاً رایگان روزانه الان استفاده نشده.
