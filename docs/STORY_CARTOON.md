# موتور قصه کارتونی معنوی (CPU)

## ایده
راوی داستان را کامل می‌گوید؛ هر جمله یک صحنهٔ کارتونی هماهنگ.

## سبک ثابت
- کتاب کودک / کوهستان آلپ (نرم، ساده، نور گرم)
- نه فتورئال، نه سه‌بعدی سنگین

## ابزار رایگان
| بخش | ابزار |
|-----|--------|
| تصویر | Pollinations (پرامپت cartoon storybook) |
| صدا | Edge-TTS فارسی |
| فونت | Vazirmatn |
| مونتاژ | FFmpeg |

## اجرای دستی
```bash
python scripts/render_story_cartoon.py output/story_cartoon
```

## موتورهای مرتبط (مطالعه)
- **Story-Flicks** — داستان→تصویر→صدا→فیلم (نیاز به کلید مدل برای بعضی بخش‌ها)
- **vector-toon-pipeline** — SVG + CPU واقعی، بدون diffusion
- **cartoonimator** — ماسکات + لیپ‌سینک روی CPU
- مسیر ما: سبک Story-Flicks با صفر هزینه API پولی

## داستان اول
«پسر کوهستان» — نزدیکی خدا از راه مهربانی عملی
