# BAMO Manim CPU Engine Prototype

This branch evaluates Manim Community Edition as a specialist engine for math/science motion graphics.

- Engine: Manim Community Edition 0.22.1
- Renderer: Cairo (CPU)
- Reference scene: `examples/manim_neon_reference.py`
- CI: `.github/workflows/bamo-manim-engine.yml`

The sample demonstrates layered neon strokes, orbital particles, geometric connections, lattice transformation, radial spokes, and camera framing.

This is an isolated prototype. It does not replace BAMO Neon, Blender, or the production renderer, and it is not yet connected to the 11-agent pipeline. The uploaded MP4 does not contain reliable provenance identifying its original authoring software. Visual equivalence must be judged by rendering and comparing actual frames.
