# BAMO CPU-first Hybrid Video Engine

## هدف
این موتور برای رندر روزانه روی GitHub Actions با CPU طراحی شده است. تولید پایه به GPU، API پولی یا دانلود مدل هوش مصنوعی وابسته نیست.

## زنجیرهٔ تولید ۱۱ نقش
۱) کشف موضوع و منابع؛ ۲) برنامه‌ریزی و تقویم؛ ۳) متن و هوک؛ ۴) عنوان و متن تصویر؛ ۵) SEO؛ ۶) مدیریت تولید و تبدیل خروجی نقش‌ها به JSON صحنه‌ها؛ ۷) تدوین؛ ۸) بازتولید Shorts؛ ۹) فصل‌بندی؛ ۱۰) مدیریت نظرات؛ ۱۱) تحلیل عملکرد و نگهداشت.
موتور رندر در مرحلهٔ ششم فراخوانی می‌شود. این ادغام، renderer اجرایی را فراهم می‌کند؛ به‌تنهایی به معنی اجرای خودکار ۱۱ مدل/عامل مستقل نیست. اتصال orchestrator باید خروجی واقعی هر نقش را به قرارداد JSON موتور متصل کند.

## فناوری و مرز قابلیت‌ها
- FFmpeg (الزامی): رندر CPU، ترکیب صحنه‌ها، حرکت‌های ساده، زیرنویس ASS، صدا و MP4.
- Remotion (اختیاری/مرحلهٔ بعد): قالب‌های React و موشن‌گرافیک پیچیده؛ وابستگی اجباری مسیر پایه نیست.
- Manim (اختیاری): فرمول‌ها، نمودارها، هندسه و محتوای علمی.
- Blender (اختیاری): صحنه‌های سه‌بعدی خاص؛ رندر CPU ممکن است ولی کند است و فایل پروژه لازم دارد.
- تصاویر سینمایی: تصاویر محلی با زوم/پن متحرک می‌شوند. موتور پایه تصویر مولد AI تولید نمی‌کند.
- افکت‌ها: پنل‌های متحرک، رنگ‌بندی، نویز ظریف، فید و زیرنویس.

## قرارداد ورودی
JSON دارای format و scenes است. هر صحنه duration و text یا on_screen_text می‌پذیرد؛ image مسیر تصویر محلی اختیاری است.
- Shorts عمودی: 720×1280
- ویدئوی افقی: 1280×720
- مربع: 1080×1080

نمونه در examples/bamo_motion_project.json قرار دارد.

## اجرا
    sudo apt-get update && sudo apt-get install -y ffmpeg fonts-noto-core
    python scripts/render_bamo_motion.py --project examples/bamo_motion_project.json --output output/bamo/preview.mp4

برای افزودن نریشن، آرگومان --audio path/to/narration.mp3 را اضافه کنید.

## ایمنی انتشار
Workflow فقط پیش‌نمایش dry-run می‌سازد و MP4 را به‌صورت artifact نگه می‌دارد. هیچ OAuth یا YouTube upload انجام نمی‌شود. انتشار عمومی/خصوصی مرحله‌ای جداگانه و نیازمند تأیید صریح است.

## وضعیت
این نسخه موتور CPU قابل اجرا و قرارداد JSON را اضافه می‌کند. تولید تصویر AI، صحنه‌های 3D کامل و اتصال end-to-end همهٔ ایجنت‌ها هنوز در محدودهٔ این commit نیستند و نباید تکمیل‌شده تلقی شوند.
