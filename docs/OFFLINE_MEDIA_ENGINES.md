# Offline media engines

این مسیر برای تولید صدای فارسی و تصویر ویدئو به **API تولید صدا یا ویدئو** وابسته نیست.

## صدای گوینده

- موتور پیش‌فرض: `piper-tts`
- مدل پیش‌فرض: [`MahtaFetrat/Mana-Persian-Piper`](https://huggingface.co/MahtaFetrat/Mana-Persian-Piper)
- کد اتصال: `app/piper_tts.py`
- مسیر orchestration: `app/spiritual_tts.py`
- دانلود وزن فقط در اولین اجرا انجام می‌شود؛ بعد از آن inference محلی است.
- متن معمول فارسی مستقیماً به Piper داده می‌شود و برای کپشن‌ها زمان‌بندی واژه‌ایِ قطعی بر اساس مدت واقعی صدا ساخته می‌شود.

### تنظیم صوتی مرجع

ویدئوی مرجع یک گویندهٔ زنِ فارسی با اجرای آهسته و تأملی، صدای نزدیک به میکروفون و tail کوتاهِ فضای بزرگ دارد. برای نزدیک‌شدن به آن، MP3 محلی با این زنجیرهٔ ملایم ساخته می‌شود:

1. حذف rumble زیر ۷۰ هرتز؛
2. محدودکردن فرکانس‌های بالای تیز؛
3. سه انعکاس کوتاه و کم‌عمق با `aecho`؛
4. loudness normalization برای نشستن صدا روی موسیقی.

ترک `sound-effects.wav` نیز بدون asset یا API خارجی ساخته می‌شود: قدم‌های کوتاه در صحنه‌های ۱ و ۲ و shimmer نور طلایی در صحنه‌های ۳ و ۴. زمان شروع رویدادها از `scene_timings` واقعی گویندگی گرفته می‌شود، نه از تقسیم مساوی مدت ویدئو. موسیقی و افکت‌ها با sidechain compression زیر صدای گوینده duck می‌شوند تا کلمات پوشانده نشوند.

این افکت جای صدای استودیوییِ واقعی را نمی‌گیرد. پذیرش production باید با شنیدن نمونهٔ خروجی و بازبینی native فارسی انجام شود.

برای خاموش‌کردن پس‌پردازش:

```bash
PIPER_AUDIO_FILTER=\"\"
```

برای تولید درآمدزا، مجوز **وزن، داده، صدای مرجع و assetهای ویدئویی** را جداگانه ثبت کنید؛ مجوز کد به‌تنهایی مجوز وزن یا خروجی را تعیین نمی‌کند.

## تولید تصویر و حرکت

- موتور محلی اختیاری: [Wan2.1](https://github.com/Wan-Video/Wan2.1). پروفایل پیش‌فرض `cinematic` از وزن ۱۴B برای کیفیت بالاتر استفاده می‌کند؛ `low_memory` وزن ۱٫۳B را انتخاب می‌کند.
- کد اتصال: `app/wan_video_engine.py`.
- فعال‌سازی: `AI_VIDEO_ENGINE=wan`.
- Wan روی GPU دارای CUDA اجرا می‌شود؛ پروفایل سینمایی حداقل ۲۴ گیگابایت VRAM آزاد می‌خواهد و پروفایل کم‌حافظه برای مسیر ۱٫۳B حدود ۸٫۱۹ گیگابایت لازم دارد.
- promptهای صحنه بر اساس سبک ویدئوی مرجع به چهار ضرب تصویری تبدیل می‌شوند: نمای ماکرو از قدم‌ها، تعقیب از پشت، آشکارشدن درخت نورانی و نمای پایانی آرام. seed ثابت باعث می‌شود رنگ و حس بصری بین اجراها قابل تکرارتر باشد.
- روی runner استاندارد GitHub Actions که GPU ندارد عمداً fail-closed می‌شود و به stock footage جعلی برنمی‌گردد.
- خروجی تصویر، صدا، کپشن و میکس نهایی با FFmpeg در همین مخزن انجام می‌شود.

## وضعیت فورک GitHub

درخواست ساخت fork خودکار برای `Adibian/Persian-TTS-Zoo` از GitHub با خطای دسترسی `HTTP 403 Resource not accessible by integration` رد شد؛ بنابراین هیچ fork ناقص یا جعلی در مخزن ثبت نشده است. اتصال production به‌جای کپی‌کردن یک پروژهٔ قدیمی، از Piper و checkpoint فارسی آماده استفاده می‌کند و لینک upstream را در همین سند نگه می‌دارد. برای ساخت fork واقعی، مالک مخزن باید از حساب GitHub خودش آن را fork کند یا مجوز GitHub App را افزایش دهد.

## محدودیت مهم

«رایگان و بدون API» به معنی «بی‌هزینه و بی‌نیاز از سخت‌افزار» نیست: وزن‌ها باید یک‌بار دانلود شوند، inference به CPU/GPU و دیسک نیاز دارد، و Wan برای ویدئوی سینمایی واقعی به GPU نیازمند است. مدل‌های F5-TTS، XTTS-v2 و MMS فارسی به‌دلیل مجوزهای غیرتجاری، انتخاب پیش‌فرض این خط تولید نیستند.
