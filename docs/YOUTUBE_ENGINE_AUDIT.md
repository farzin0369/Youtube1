# گزارش وضعیت موتور LTX-Video و مهارت‌های YouTube Agent

تاریخ: ۲۰۲۶-۱۰-۲۴  
مخزن: [farzin0369/Youtube1](https://github.com/farzin0369/Youtube1)  
شاخهٔ تغییرات: `feat/youtube-agent-skill-integration`  
این گزارش کد را بررسی می‌کند؛ تولید واقعی روی GPU و آپلود آزمایشی در این مرحله اجرا نشده‌اند.

## مسیر اصلی کانال ImamAli110

مسیر اصلی در این شاخه اکنون چنین است:

`scripts/daily_run.py → app/spiritual_pipeline.py → app.ltx_spiritual_renderer.py → app.ltx_video_engine.py`

- **متن:** `app/spiritual_shorts.py` برای Shorts با چهار ضرب روایی و `app/spiritual_content.py` برای ویدئوی بلند فارسی. کنترل‌های هوک، تکرار، سیاست محتوا و تطابق متن حفظ شده‌اند.
- **گویندگی:** `app/spiritual_tts.py` با صدای فارسی `fa-IR-FaridNeural` و زیرنویس زمان‌بندی‌شده. در Colab از Edge TTS و Ollama محلی استفاده می‌شود؛ کلید API پولی برای متن لازم نیست.
- **تصویر مولد:** `app/ltx_video_engine.py` موتور انتخاب‌شده است. برای هر صحنه prompt مشخص می‌سازد/می‌پذیرد، checkpoint قابل‌بازیابی دارد و طول صحنه‌ها را با مدت واقعی روایت مقیاس می‌کند. Shorts خروجی 1080×1920 و ویدئوی بلند 1920×1080 می‌گیرد.
- **مونتاژ:** `app/ltx_spiritual_renderer.py` ویدئوی LTX را با گویندگی mux می‌کنند، زیرنویس فارسی را می‌سوزانند و کاور می‌سازند. در Shorts هوک مجزا و ASS با انیمیشن phrase-level حفظ می‌شود.
- **کیفیت:** `app/media_qa.py` ابعاد، مدت، صدا، زیرنویس، کاور و منبع بصری را بررسی می‌کند. `app/youtube_growth_agent.py` نیز پیش از آپلود، هوک، بسته‌بندی عنوان/کاور، SEO، تکرار عنوان و تطابق صحنه/روایت را بازبینی می‌کند؛ امتیازهایش پیش‌بینی ویو نیستند.
- **تعامل کانال:** پس از آپلود خصوصی، مسیر پاسخ‌گویی موجود در `app/spiritual_comments.py` فقط تعداد محدودی نظر بی‌خطر و روشن را بررسی می‌کند؛ نظر حساس، بحرانی یا نامطمئن باید بدون پاسخ خودکار بماند.
- **انتشار:** کد مسیر اصلی فقط بارگذاری `private` را مجاز می‌داند. هیچ انتشار عمومی یا زمان‌بندی خودکار عمومی فعال نیست.

## محدودیت اجرایی GPU و زمان‌بندی

`Lightricks/LTX-Video` نیازمند GPU سازگار، VRAM و زمان تولید است. GitHub-hosted `ubuntu-latest` در این مخزن GPU CUDA ندارد. نشست رایگان Colab هم از GitHub قابل بیدارکردنِ قابل‌اعتماد در زمان‌بندی روزانه نیست.

به همین دلیل:
- زمان‌های هدف در `config/channel.yaml` تعریف شده‌اند: ویدئوی بلند `14:00 UTC` و Shorts `17:00 UTC`.
- workflow زمان‌بندی‌شدهٔ CPU غیرفعال شده تا ویدئوی stock یا خروجی ناقص تولید/منتشر نشود.
- مسیر واقعی GPU در `colab/ImamAli110_Cinematic_Production.ipynb` است؛ پیش‌فرض آن dry-run و بدون آپلود است.
- فعال‌کردن زمان‌بندی خودکار کامل به یک GPU runner همیشه‌در‌دسترس نیاز دارد. این محدودیت زیرساختی را نمی‌توان با کد یا secret به‌تنهایی برطرف کرد.

## یازده مهارت YouTube Agent

همهٔ یازده مهارت بالادستی و شش ابزار کمکی به‌همراه مجوز MIT در `.claude/skills/yt-*/` ذخیره شده‌اند:
`yt-audit`, `yt-chapters`, `yt-comment`, `yt-edit`, `yt-package`, `yt-plan`, `yt-retention`, `yt-script`, `yt-seo`, `yt-shorts`, `yt-viral`.

در مسیر Python فعلی، قابلیت‌های متن/هوک، بسته‌بندی، SEO، QA، تاریخچهٔ موضوع و پاسخ محدود به نظرها فعال‌اند؛ بررسی retention واقعی و تحلیل رقبا به دادهٔ تازهٔ YouTube Analytics/رقبا نیاز دارد، و ابزار تدوین transcript/dead-air به‌صورت دستور مستقل باقی مانده است. صرف نگهداری فایل‌های `SKILL.md` به معنی اجرای خودکار آن‌ها توسط GitHub Actions نیست.

## اعتبارسنجی

تست‌های CPU-only برای قواعد صحنه/مدت LTX، تطابق دقیق روایت، مهارت‌ها، SEO و گیت کیفیت اضافه شده‌اند. تا زمان مشاهدهٔ CI سبز و یک رندر واقعی Colab، سازگاری API مدل، مصرف VRAM، مدت واقعی رندر و کیفیت بصری هنوز تأییدشده محسوب نمی‌شوند. هیچ آپلود یا انتشار واقعی در این تغییرات انجام نشده است.
