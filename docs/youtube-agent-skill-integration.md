# ادغام YouTube Agent Skill در خط تولید ImamAli110

## نتیجهٔ بررسی
مخزن بالادستی [Jakeschincariol/youtube-agent-skill](https://github.com/Jakeschincariol/youtube-agent-skill) یک بستهٔ رایگان و MIT از ۱۱ مهارتِ برنامه‌ریزی و بهینه‌سازی کانال است؛ خودش موتور ساخت ویدئو نیست. متن، هوک، عنوان/متن thumbnail، طرح ویرایش از روی transcript، پاسخ پیشنهادی به کامنت، SEO، فصل‌بندی، تحلیل retention و پیدا کردن ایده‌های Shorts را کمک می‌کند. شش ابزار Python آن بدون وابستگی اضافی‌اند.

**محدودیت مهم:** نسخهٔ اصلی برای Claude Code و فرمان‌هایی مثل `/yt-script` ساخته شده است. کپی‌کردن آن به GitHub Actions به‌تنهایی این فرمان‌ها را فعال نمی‌کند؛ همچنین خودش ویدئو را رندر یا در YouTube منتشر نمی‌کند. برای تولید واقعی، رندر و آپلود همچنان وظیفهٔ خط تولید موجود این مخزن است.

## این شاخه چه اضافه می‌کند؟
- `scripts/youtube_growth_review.py`: بازبین مقدماتی و رایگان برای هوک فارسی و هماهنگی عنوان/متن thumbnail؛ فقط Python استاندارد، بدون API یا کلید.
- این ابزار عمداً **پیش‌بینی وایرال‌شدن نمی‌کند** و خودش عنوان/اسکریپت تولید نمی‌کند؛ فقط به متن‌های آماده بازخورد می‌دهد.
- به خط تولید فعلی دست نمی‌زند و چیزی را خودکار منتشر نمی‌کند؛ بنابراین رفتار زمان‌بندی/آپلود موجود تغییر نمی‌کند.

## اجرا از گوشی یا GitHub
در GitHub این فایل را باز کن و از گزینهٔ Raw کد را می‌توان دید؛ برای اجرای ابزار، در محیط Python:
```bash
python scripts/youtube_growth_review.py --hook "چرا بعضی وقت‌ها درست قبل از تغییر، تسلیم می‌شویم؟" --title "چرا نباید همین حالا تسلیم شوی" --thumb "یک قدم دیگر"
```

## ارتباط با ساخت ویدئو
پیشنهاد کاربردی برای هر ویدئوی جدید:
1. ایده و هوک را پیش از تولید بررسی کن.
2. عنوان را با متن تصویر بندانگشتی مقایسه کن تا دقیقاً یک جمله را تکرار نکنند.
3. اسکریپت نهایی را به خط تولید فعلی بسپار تا صدا، صحنه‌ها، زیرنویس و MP4 را طبق quality gateهای خودش بسازد.
4. قبل از انتشار، خود ویدئو را ببین؛ این ابزار کیفیت صدا، تناسب واقعی footage یا جذابیت را نمی‌تواند تشخیص دهد.

## وضعیت این ادغام
این یک ادغام محدود و ایمن از ایدهٔ پروژهٔ بالادستی است، نه انتقال کامل ۱۱ skill و نه اتصال به Claude. انتقال کامل نیازمند سازگارکردن هر مهارت با runner/عامل واقعی این مخزن و آزمون جداگانه است. مجوز بالادستی MIT است؛ هنگام کپی مستقیم فایل‌های بالادستی باید متن مجوز و انتساب آن نیز همراه فایل‌ها منتقل شود.
