# موتورهای TTS برای فارسی — واقعیت کیفیت

## وضعیت واقعی (۲۰۲۶)

| موتور | طبیعی بودن | رایگان؟ | یادداشت |
|-------|------------|---------|----------|
| **ElevenLabs** (multilingual v2) | ★★★★★ | اعتبار محدود رایگان | بهترین گزینه عملی برای یوتیوب |
| **Google Cloud Neural2 / WaveNet fa-IR** | ★★★★☆ | پولی | نیاز به API |
| **Azure fa-IR-Farid/Dilara Neural** | ★★★☆☆ | از طریق edge-tts رایگان | همان Edge — قابل قبول، نه انسانی |
| **Mana-Persian-Piper** | ★★☆☆☆ | بله | واضح‌تر از MMS، هنوز مصنوعی |
| **MMS-TTS-fas** | ★☆☆☆☆ | بله | رباتیک |
| **pocket-tts-farsi-v2** | ★★★★☆ (ادعا) | بله ولی پیچیده | نیاز G2P + نمونه صدا + fork |
| **Ava-82M** | ★★★☆☆ | بله | نصب سنگین / ناپایدار روی py3.12 |

**نتیجه:** برای «کاملاً طبیعی» روی کانال یوتیوب، فعلاً **ElevenLabs** یا **Google Cloud** لازم است.

## پیشنهاد عملی BAMO

1. Secret: `ELEVENLABS_API_KEY`
2. موتور پیش‌فرض صدا: ElevenLabs multilingual (صدا مرد فارسی‌پسند)
3. Fallback: Edge-TTS Farid فقط اگر کلید نبود

بدون کلید API نمی‌توان کیفیت گوینده حرفه‌ای انسانی را از مدل‌های کاملاً رایگان گرفت.
